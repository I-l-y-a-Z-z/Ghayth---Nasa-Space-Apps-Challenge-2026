# Public demo deployment

Public URL: **https://ghayth-demo.pages.dev/app/**

The site is deployed on Cloudflare Pages Free. Railway authentication succeeded, but Railway rejected project creation because the account's trial has expired. No paid plan was selected. The currently published version therefore uses the hardcoded fallback requested for exhausted allowance.

The original interface provides the map, farm forms, prepared one-, two- and three-year rotations, sample typed chat, printing and browser-local saved plans. A visible notice identifies the prepared synthetic inputs/results. Changes to dates, boundaries and farm answers do not run new scientific calculations. Duration changes select the corresponding prepared examples. No server speech inference runs. Records from the hosted Neon database are not exposed in this fallback.

`apps/web/public/demo-fixtures.json` contains public synthetic examples generated by the existing engine. `apps/web/src/demo.ts` supplies the browser-local fallback and uses a separate local-storage namespace. `infrastructure/cloudflare/pages-worker.js` serves the site and can proxy API traffic to `GHAYTH_BACKEND_ORIGIN`. When that backend returns quota/unavailability errors or cannot be reached, the client switches to the labeled sample mode. Mutation requests are never replayed to the backend.

To rebuild and publish with Node 24 from the repository root:

```bash
npm run check
node scripts/build-demo-host.mjs
infrastructure/cloudflare/node_modules/.bin/wrangler pages deploy .cache/demo-host --project-name ghayth-demo --branch main --commit-dirty=true
```

An authorized operator can later set the `GHAYTH_BACKEND_ORIGIN` Pages production secret to a working backend's HTTPS origin and redeploy. The frontend URL stays the same; a backend that exceeds its allowance falls back to the public sample interface. Existing local development and full Python deployment paths remain available.

Verified on the public site in Chrome: changing the rotation duration reloads examples; a saved plan survives refresh; typed sample chat responds; no JavaScript errors occur. The proxy's quota fallback and single-attempt POST behavior were checked separately. The root development `.env` is preserved, and no database password or deployment secret is included in the public assets.
